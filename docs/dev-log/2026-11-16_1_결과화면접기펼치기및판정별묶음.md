# ColorLens CVDS 개발일지

## 2026-11-16 작업 내용

### 1. 대응 적용 이미지 비교 탭에서 해결 방법·요약 숨김

#### 배경
- 개발자 모드 이미지 검사 결과에 두 개 탭("검사 결과 및 대응 방안" / "대응 적용 이미지 비교")이 있음.
- "대응 적용 이미지 비교" 탭을 눌렀을 때도 하단의 "문제 해결 방법" 카드와 "검사 결과 요약"이 함께 노출되어 있었음.
- 비교 화면에서는 Before/After 이미지에 집중하도록, 해결 방법·요약은 "검사 결과 및 대응 방안" 탭에서만 보이는 게 자연스러움.

#### 구현 내용
- `frontend/src/pages/DeveloperModePage.tsx`:
  - "문제 해결 방법 + 요약" 영역의 렌더링 조건을 `hasResult` → `hasResult && (codeResult || resultTab === 'analysis')`로 변경.
  - 이미지 모드에서 "대응 적용 이미지 비교" 탭(`resultTab === 'compare'`)일 때는 해결 방법·요약 영역이 렌더링되지 않음.
  - 코드 모드는 탭이 없으므로 항상 표시되도록 `codeResult` 조건 포함.
  - 코드 분석 실행 시 `setResultTab('analysis')`로 결과 탭을 분석 탭으로 초기화 (상태 일관성 유지).

### 2. 중복 안내 문구를 하나의 요약 상자로 통합

#### 배경
- 이미지 모드 결과 내용에 결이 비슷한 안내 문구가 두 개 나뉘어 표시되고 있었음:
  1. `imgResultIntro`: "선택한 색각이상 유형을 기준으로 검사한 결과, 주의가 필요한 색상 조합 N개가 발견되었습니다. 아래에서 문제가 발견된 색상과 더 잘 구분되는 추천 색상을 확인해 보세요."
  2. AI/fallback 요약 설명(`ai.summary`): "선택한 색각이상 환경에서 N곳의 색이 서로 잘 구분되지 않을 수 있어요. 아래에서 어떤 색이 겹쳐 보이는지와 바꿔볼 수 있는 색을 확인해 보세요."
- 두 내용이 거의 같은 의미를 전달해 중복·잡음이 발생.

#### 구현 내용
- `frontend/src/components/ResultSummary.tsx`:
  - 기존 두 블록(`imgResultIntro` 안내 문구 + AI 설명 박스)을 하나의 요약 상자로 통합.
  - AI 응답이 있으면 `ai.summary`를, 없으면 `imgResultIntro`/`imgResultIntroOk`를 fallback으로 사용.
  - 출처 라벨(`aiExplain` / `plainExplain`)은 유지해 AI 설명인지 템플릿 요약인지 구분.
  - 개발자 모드는 항상 표시, 사용자 모드는 AI 응답이 있을 때만 표시.

### 3. 결과 내용·문제 해결 방법 접기/펼치기 도입

#### 배경
- 검사 결과가 한 번에 펼쳐져 있어 정보량이 많고 스크롤이 길어짐.
- 결과 요약(판정 + 요약 설명)은 항상 보이되, 상세 영역(주요 색상·발견된 문제·추천 색상)과 문제 해결 방법 카드는 접었다 펼치는 형태가 좋겠다는 요청.

#### 구현 내용
- `frontend/src/components/ResultSummary.tsx`:
  - `collapsible` prop 추가 (기본 `false`).
  - `collapsible=true`일 때 상세 영역(주요 색상/문제/추천)이 기본 접힘, "펼쳐 보기/접기" 버튼(`aria-expanded`)으로 토글.
  - 판정 배지 + 요약 설명 상자는 접기 여부와 무관하게 항상 노출.
- `frontend/src/pages/DeveloperModePage.tsx`:
  - 이미지 모드 `ResultSummary`에 `collapsible` 적용.
  - "문제 해결 방법" 카드 영역도 동일하게 기본 접힘 + 토글 버튼 적용 (`solutionsOpen` 상태).
  - 기존 "↓ 문제 해결 방법 보기" 둥근 버튼 제거 (접기/펼치기 헤더가 대체).
  - 사용하지 않게 된 `solutionsRef`, `useRef` import, `scroll-mt-4` 정리.
  - 코드 모드 결과 표도 `codeDetailOpen` 상태로 접기/펼치기 적용 (판정·결과 메시지는 항상 보임).
- `frontend/src/components/CodeResultDetail.tsx` (결과 내역):
  - 결과 표(`detailOpen`)와 문제 해결 방법 카드(`solutionsOpen`) 모두 접기/펼치기 적용.
- `frontend/src/pages/ResultHistoryPage.tsx`:
  - 결과 내역의 이미지 모드 `ResultSummary`에 `collapsible` 추가 (누락 보완).

#### 접근성
- 접기/펼치기 버튼에 `aria-expanded` 속성 부여 — 스크린리더가 펼침/접힘 상태 인식.
- 화살표 아이콘(▲/▼)은 `aria-hidden`으로 장식 처리.

### 4. 코드 검사 결과 표를 판정별 묶음으로 그룹화

#### 배경
- 코드 모드 검사 결과 표가 요소마다 PASS/WARNING/FAIL을 한 행씩 나열하는 구조.
- 같은 판정끼리 묶어 보면 한눈에 "몇 개가 통과/주의/개선필요인지" 파악하기 쉬움.

#### 구현 내용
- `frontend/src/components/CodeResultTable.tsx` (신규):
  - 요소별 결과(`ElementResult[]`)를 판정(FAIL → WARNING → PASS) 순으로 그룹화.
  - 각 묶음 머리에 판정 배지(`VerdictBadge`) + 해당 판정 요소 개수 표시.
  - 묶음 안 표에서는 판정 열을 생략(묶음 머리가 대신)하고 선택자/글자색/배경색만 표시.
  - 빈 묶음(해당 판정 요소 없음)은 표시하지 않음.
- `frontend/src/pages/DeveloperModePage.tsx` 및 `frontend/src/components/CodeResultDetail.tsx`:
  - 기존 인라인 표를 `CodeResultTable` 컴포넌트로 교체.

#### 참고: 코드 검사 판정 기준
- 코드 검사에서도 WARNING은 정상적으로 발생:
  - PASS: 일반 텍스트 기준(4.5:1) 통과
  - WARNING: 일반 텍스트 기준 미달이지만 큰 텍스트 기준(3:1) 통과
  - FAIL: 큰 텍스트 기준(3:1)에도 미달
- 판정 로직은 `backend/app/services/wcag.py`에 있으며 변경 없음.

### 5. "문제 해결 방법" 제목을 박스 헤더로 통합

#### 배경
- "문제 해결 방법" 제목이 결과 내용처럼 박스 안이 아니라 배경에 그냥 떠 있어 시각적 일관성이 깨짐.

#### 구현 내용
- `frontend/src/pages/DeveloperModePage.tsx` 및 `frontend/src/components/CodeResultDetail.tsx`:
  - "문제 해결 방법" 제목을 접기/펼치기 박스 헤더 안으로 이동.
  - 제목 + ⓘ 팝오버 + "펼쳐 보기/접기" 텍스트 + 화살표가 하나의 박스 헤더에 통합.
  - "결과 내용" 표도 동일하게 제목을 박스 헤더에 배치 (`CodeResultDetail`).
