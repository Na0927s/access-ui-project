# ColorLens CVDS 개발일지

## 2026-11-13 작업 내용

### 1. 문제 해결 방법 카드 — 색상 코드 옆 실제 색 견본 표시 (SolutionCards.tsx)
- **배경**: 개발자 모드의 "문제 해결 방법" 카드에서 색상 코드(`#RRGGBB`)가 텍스트로만 표시되어,
  개발자가 추천 색이나 대상 색이 실제 어떤 색인지 한눈에 파악하기 어려웠음.
- **목표**: 카드에 등장하는 모든 색상 코드 옆에 실제 색 사각형(색 견본)을 함께 보여주기.

#### 구현 내용
- `ColorChip` 컴포넌트를 import하여 재사용 (이미 코드 분석 테이블·팔레트 등에서 쓰던 컴포넌트).
- **`extractAllHex(text)`** 헬퍼 추가
  - 텍스트에서 모든 `#RRGGBB` 패턴을 발생 순서대로 추출 (중복 포함).
  - 정규식: `/#[0-9a-fA-F]{6}\b/g`
- **`renderTextWithColors(text)`** 헬퍼 추가
  - 텍스트를 `#RRGGBB` 기준으로 분할(`split`)해, 매칭된 부분은 `ColorChip`(색 사각형+hex)으로,
    나머지는 일반 텍스트(`Fragment`)로 렌더링.
  - selector(색상 쌍) 등 인라인 텍스트에 사용.

#### 카드 내 영역별 적용
| 영역 | 색 견본 표시 | 비고 |
|------|------------|------|
| selector (카드 머리, 색상 쌍) | ✅ 표시 | `renderTextWithColors` 적용 |
| problem (문제 설명 본문) | ❌ 미표시 | 일반 텍스트로만 — 사용자 요청으로 색 견본 제외 |
| css_fix 코드 블록 | 코드 자체 표시 | `pre` 블록 그대로 |
| css_fix 아래 견본 나열 | ✅ 표시 | `extractAllHex`로 코드 내 모든 색(원본→추천 등)을 한 줄로 나열 |

- **문제 설명(problem)은 색 견본 제외**: 본문 안의 색상 코드는 일반 텍스트로만 표시.
  (스크린샷으로 지정한 영역 — 색 견본이 본문 흐름을 방해하지 않도록 함.)
- **css_fix 아래 견본 나열 영역**: 이미지 모드(`/* #old → */ color: #new;`)와
  코드 모드(`selector { color: #new; }`) 모두에서 추천 색을 올바르게 잡도록
  마지막 매치가 아닌 **모든 매치**를 나열.

### 2. 좀비 프로세스 정리
- 이전 세션에서 종료되지 않고 남아있던 node/python 백그라운드 서버들이
  포트 5176~5179, 8002를 차지하고 있어 Vite가 포트를 계속 밀려 올리던 문제 해결.

  - venv 재생성 대신 **시스템 Python으로 우회 실행**:
    `C:\Users\mj465\AppData\Local\Programs\Python\Python312\python.exe -m uvicorn ...`
  - 시스템 Python에 fastapi·uvicorn·sqlalchemy·pillow·numpy·bcrypt 모두 설치되어 있어 정상 동작.
- 백엔드: http://127.0.0.1:8002 / 프론트엔드: http://localhost:5176 (또는 5177 등)

### 4. 개발자 모드 코드 검사용 예시 코드 제공
- 색각이상 사용자에게 문제가 될 만한 요소를 의도적으로 포함한 HTML/CSS 예시 작성:
  - 낮은 대비(subtitle `#999999`, link `#90caf9` on white)
  - 색으로만 구분(두 버튼 `#1976d2` vs `#1565c0`, 상태 배지)
  - 적녹 혼동(warning 노란 배지)
- 이 코드로 개발자 모드 → 코드 탭 검사 시 추천 색상·문제 해결 카드가 잘 뜨는지 검증용.
