# ColorLens CVDS 개발일지

## 2026-11-17 작업 내용

### 1. 개발자 모드 "대응 적용 이미지 비교" 기능 제거

#### 배경
- 개발자 모드 이미지 검사 결과에 "대응 적용 이미지 비교" 탭(Before/After 2×2 그리드)이 있었다.
- 추천 색상을 이미지 픽셀에 적용한 "대응 이미지"와 그 시뮬레이션을 백엔드에서 생성해 프론트엔드로 내려주는 구조.
- 기능을 정리하기로 결정 → 프론트엔드·백엔드 양쪽에서 관련 코드·메시지·타입·설정·캐시 가드까지 모두 제거.

#### 프론트엔드 변경

**`frontend/src/components/ImprovedCompare.tsx` — 삭제**
- 2×2 비교 그리드 컴포넌트(원본/대응이미지 + 각 시뮬레이션) 통째로 삭제.

**`frontend/src/pages/DeveloperModePage.tsx` — 탭 구조 단순화**
- 제거: `ImprovedCompare` import, `RESULT_TABS` 상수, `resultTab` state, `resultTabs`(useRovingTabs), `resultUid/resultPanelId/resultTabId`, `hasCompare` 계산, compare 탭 렌더 블록.
- 제거: 이미지 분석 성공 시 `setResultTab('analysis')` 호출 2곳.
- 변경: 이미지 결과 영역을 탭 없이 `ResultCompare` + `ResultSummary`만 직접 렌더하도록 평탄화.
- 변경: 문제 해결 방법·요약 표시 조건 `(codeResult || resultTab === 'analysis')` → `hasResult`만으로 단순화.

**`frontend/src/api/types.ts` — 타입 필드 제거**
- `ImageAnalysis`에서 `improved_image`, `improved_simulated_image` 필드 제거.

**`frontend/src/i18n/messages.ts` — 메시지 키 제거 (ko/en)**
- 제거 키: `tabAnalysis`, `tabCompare`, `beforeLabel`, `afterLabel`, `originalSimLabel`, `improvedLabel`, `improvedSimLabel`, `compareCaption`, `altImproved`, `altImprovedSim`.

#### 백엔드 변경

**`backend/app/services/analyzer.py`**
- `_apply_replacements` 함수 전체 제거 — 추천 색상 매핑을 픽셀에 적용해 대응 이미지를 만들던 로직.
- `_analyze_image_core` 내 개발자 모드 improved_image/improved_simulated_image 생성 블록 제거.
- import 정리: 미사용이 된 `numpy`, `hex_to_oklab`, `hex_to_rgb`, `linear_to_oklab`, `srgb_to_linear`, `flatten_on_white` 제거.
- `__all__`에서 `flatten_on_white` 제거 (analyzer 재노출 목적이 사라짐; palette 모듈에서 직접 import 가능).

**`backend/app/routers/analysis.py`**
- 캐시 무효화 가드에서 "개발자 모드에서 추천이 있는데 improved_image가 없으면 구버전 캐시 → 재분석" 로직 제거.
- 남은 가드(issues에 message만 있고 fg/a 없으면 구버전)는 유지.

**`backend/app/config.py`**
- 미사용 상수 `APPLY_REPLACE_DISTANCE`(=0.10) 제거.

#### 캐시 호환성
- 기존 캐시에 `improved_image`가 남아 있어도 프론트가 더 이상 참조하지 않아 기능적 영향 없음.
- 새 분석 결과로 자연스럽게 교체됨.

## 규칙 준수 사항

- **규칙 3 (이미지 비저장)**: `_apply_replacements` 제거 후에도 이미지는 여전히 BytesIO/메모리에서만 처리. improved 이미지도 디스크·DB에 쓰지 않고 data URL로만 반환하던 기존 방식 유지(이제는 생성 자체를 안 함).
- **규칙 5 (알고리즘 기준)**: 시뮬레이션·대비·추천 핵심 알고리즘은 무관. `_apply_replacements`는 표시용 픽셀 교체 로직이었으므로 제거해도 판정·추천 결과에 영향 없음.
- **규칙 8 (서비스 자체 접근성)**: 탭이 제거되면서 WAI-ARIA Tabs 의존이 줄었고, 결과는 단일 화면으로 더 단순하게. 스크린리더 탐색 부담 감소.
