## 기능 요구사항

### FR-01 메인 화면 (P0)
- 헤더: 서비스 제목, Kr/En 전환, 로그인·회원가입 버튼
- 로그인 시 계정 영역: 프로필, 이름/ID, 로그아웃, '내 정보'·'결과 내역' 탭
- 본문: **왼쪽 '개발자', 오른쪽 '사용자'** 카드
- 하단: 사이트 설명·약관 링크, 푸터(대표·주소·전화), 오른쪽 아래 위로 가기 버튼

### FR-02 이미지 업로드 (P0)
- 드래그 앤 드롭 + 파일 선택 버튼, PNG/JPG/JPEG, 10MB 이하
- 오류: "지원하지 않는 파일 형식입니다. PNG, JPG, JPEG 파일만 업로드할 수 있습니다." / "파일 크기가 너무 큽니다. 10MB 이하의 이미지를 업로드해주세요."

### FR-03 사용자 모드 (P0)
- 적·녹·청 색약 유형 선택 → [검사]
- 원본 | 시뮬레이션 결과 나란히 표시
- 결과 내용: 접근성 점수, 판정, 발견된 문제, 현재 색 → 추천 색
- **"문제 해결 방법/요약" 영역은 만들지 않는다**

### FR-04 분석 엔진 (P0)
- 시뮬레이션: Machado(2009), 선형 RGB
- 주요 색상 추출과 비율
- 색상 구분 가능성: OKLab 거리
- WCAG AA: 일반 4.5:1, 큰 텍스트 3:1, UI 3:1
- 판정: PASS / WARNING / FAIL
- 접근성 점수 0~100 + "자체 지표이며 공식 WCAG 점수가 아님" 문구

### FR-05 대체 색상 추천 (P0)
- 색상(Hue)은 유지하고 밝기를 조정한 후보 생성
- 대비율과 색각이상 변환 후 구분 가능성을 **재검사해 통과한 것만** 표시
- 등급: 강력 추천 / 추천 / 조건부 추천 + 이유
- 색만으로 해결되지 않으면 비색상 개선안 제시

### FR-06 개발자 모드 (P1)
- 방식1: 화면 이미지 (FR-03과 동일 분석, 상세 결과)
- 방식2: HTML/CSS 파일 업로드 또는 붙여넣기. 입력 HTML은 실행하지 않는다
- 요소별 상세 결과: 선택자, 전경/배경색, 대비율, 판정
- 스크롤 또는 클릭으로 이동하는 **문제 해결 방법 카드**(색상 대비·명암 대비·색상 의존)와 **요약**

### FR-07 AI 설명·번역 (P1)
- 알고리즘 결과를 쉬운 문장으로 설명. 수치는 알고리즘 값만 사용
- En 전환 시 고정 문구는 번역 파일, 결과 문장은 AI 번역
- AI 실패 시 기본 문장으로 대체

### FR-08 계정 (P1, 저장하지 않음)
- 회원가입: 이름, 이메일, ID(중복 확인), 비밀번호, 비밀번호 확인, 약관 2개 동의, 가입 완료 모달
- 로그인·로그아웃, 내 정보 조회·수정
- 결과 내역: 이번 세션에서 한 분석 목록, 없으면 빈 상태 표시
- 모든 데이터는 프론트엔드 메모리에만 존재 → 새로고침·로그아웃 시 삭제

### FR-09 확장 (P2)
- URL 분석, 코드 이미지(OCR), 리포트 다운로드, 개선 전·후 비교
