## Overview

기술 요구사항 문서. 분석 알고리즘의 수식과 기준, 구현 위치를 정의한다. 이 문서의 알고리즘은 **팀원이 원리를 설명할 수 있어야 한다.**

## 1. 색 공간 변환

sRGB(0~255) → 0~1 정규화 → 선형 RGB
```
c ≤ 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ^ 2.4
```
역변환
```
c ≤ 0.0031308 ? 12.92·c : 1.055·c^(1/2.4) − 0.055
```
구현: `services/color.py` (`srgb_to_linear`, `linear_to_srgb`)

## 2. 색각이상 시뮬레이션 — Machado et al. (2009), severity 1.0

선형 RGB 벡터에 3×3 행렬을 곱한 뒤 [0,1]로 클램프, sRGB로 역변환한다. 알파 채널은 유지한다.

## 3. OKLab과 색상 거리

선형 RGB → LMS → 세제곱근 → OKLab (Björn Ottosson, 2020)
```
l = 0.4122214708 r + 0.5363325363 g + 0.0514459929 b
m = 0.2119034982 r + 0.6806995451 g + 0.1073969566 b
s = 0.0883024619 r + 0.2817188376 g + 0.6299787005 b
L = 0.2104542553 l' + 0.7936177850 m' − 0.0040720468 s'
a = 1.9779984951 l' − 2.4285922050 m' + 0.4505937099 s'
b = 0.0259040371 l' + 0.7827717662 m' − 0.8086757660 s'
```
거리: `ΔE_ok = √(ΔL² + Δa² + Δb²)`

## 4. 색상 구분 가능성 판정

| 조건 | 판정 |
|---|---|
| 원본 거리 < `DISTINCT_MIN` | 원래 비슷한 색 → 판정 제외 |
| 변환 후 거리 < `CONFUSION_FAIL` | FAIL |
| 변환 후 거리 < `CONFUSION_WARN` | WARNING |
| 그 외 | PASS |

초기값 (⚠ 팀이 샘플 UI로 실험해 조정): `DISTINCT_MIN = 0.10`, `CONFUSION_FAIL = 0.05`, `CONFUSION_WARN = 0.08`
위치: `app/config.py`

거리가 작다고 무조건 문제는 아니다. 최종 판단은 **색상 차이 + 대비율 + UI 역할 + 색상만으로 정보를 전달하는지**를 함께 본다. 이미지 모드에서 UI 역할은 알 수 없으므로 결과 문구를 "가능성이 있습니다"로 표현한다.

## 5. WCAG 대비율

```
L = 0.2126 R + 0.7152 G + 0.0722 B   (선형 값)
ratio = (L_light + 0.05) / (L_dark + 0.05)
```
표시는 소수 둘째 자리, **판정은 반올림 전 값**으로 한다.

| 항목 | AA (기본) | AAA (참고) |
|---|---|---|
| 일반 텍스트 | 4.5:1 | 7:1 |
| 큰 텍스트 (24px 이상, 또는 굵게 18.66px 이상) | 3:1 | 4.5:1 |
| UI 구성요소 | 3:1 | – |

쌍 판정: 일반 텍스트 PASS → PASS / 큰 텍스트만 PASS → WARNING / 둘 다 FAIL → FAIL

이미지 모드의 텍스트-배경 쌍: 가장 비율이 큰 색을 배경 후보로 보고, 비율 1% 이상인 나머지 색과 짝지어 검사한다. (추정이며 한계로 명시)

## 6. 주요 색상 추출

1. 흰 배경 합성 후 긴 변 400px로 축소
2. `Image.quantize(colors=16, method=MEDIANCUT)` → 색별 픽셀 수 집계
3. OKLab 거리 < 0.03 인 색 병합
4. 비율 0.5% 미만 제거 (안티앨리어싱 잡음), 상위 8개

## 7. 대체 색상 추천

1. 문제 색을 OKLab으로 변환, a·b(색조) 유지
2. L을 0.02 간격으로 어둡게·밝게 이동하며 후보 생성 (sRGB 범위 밖은 클램프)
3. 각 후보에 대해 **재검증**: 대비율 계산 + 선택 유형으로 변환 후 대상 색과의 OKLab 거리 ≥ `CONFUSION_WARN`
4. 등급: 7:1 이상 = STRONG(강력 추천), 4.5:1 이상 = RECOMMENDED(추천), 3:1 이상 = CONDITIONAL(조건부, 큰 텍스트용)
5. 원래 색과 OKLab 거리가 가까운 순으로 최대 3개
6. 후보가 없으면 비색상 개선안만 제시

## 8. 접근성 점수 (초안, ⚠ 팀 확정)

```
score = 100 − 15×(FAIL 대비 쌍) − 5×(WARNING 대비 쌍)
            − 10×(FAIL 구분 쌍) − 4×(WARNING 구분 쌍)
score = clamp(score, 0, 100)
```
항상 표시: "접근성 점수는 본 서비스의 분석 항목을 기반으로 산출한 자체 평가 지표이며 공식 WCAG 인증 점수가 아닙니다."
