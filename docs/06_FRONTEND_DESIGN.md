## Overview

React + TypeScript SPA. TailwindCSS로 스타일링, React Router로 화면 이동, Zustand로 메모리 상태 관리. 사이트 자체 색은 무채색 위주로 두어 분석 대상 이미지의 색과 섞이지 않게 한다.

## 개발자 모드 `/developer`

- [방식1 화면 이미지] / [방식2 코드] 전환 (탭, `aria-selected`)
- 방식2: `.html`/`.css` 파일 업로드 또는 HTML·CSS 붙여넣기 textarea
- 결과: 원본 | 결과 + 요소별 상세 표
- 결과 아래(버튼 클릭 또는 스크롤) **문제 해결 방법 카드**: 선택자, 검사 종류(색상 대비·명암 대비·색상 의존), 문제, CSS 수정안(복사 버튼), 비색상 개선안
- **요약**: 점수, PASS/WARNING/FAIL 개수, 우선 수정 항목

## 상태 관리 (Zustand, persist 금지)

```ts
// authStore
accounts: Account[]            // 이번 세션에 가입한 계정 (메모리)
currentUser: Account | null
signup(), login(), logout(), updateProfile(), isIdTaken()

// resultStore
results: AnalysisRecord[]      // { id, createdAt, fileName, mode, cvdType, score, data }
add(), remove(), clear()

// uiStore

```

- 새로고침 시 모든 상태 초기화 (의도된 동작)

## 접근성 규칙 (서비스 자체)

- 선택 상태·판정을 색만으로 표시하지 않는다 (아이콘, 텍스트, 테두리 병행)
- 모든 입력에 `label`, 이미지에 `alt`
- 키보드로 모든 기능 사용 가능, 포커스 링 표시
- 텍스트 대비 4.5:1 이상
- 오류 메시지는 `role="alert"`
